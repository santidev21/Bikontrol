# Internationalization (i18n)

Runtime i18n with a minimal, dependency-free service (`shared/i18n`):

- **`I18nService`** — flat `key → string` dictionaries (`translations/es.ts`, `en.ts`), a `lang`
  signal (**default `es`**, fallback `es`), `t(key, params?)` with `{param}` interpolation, and
  `setLanguage()` which persists to `localStorage` (`bikontrol.lang`) and updates `<html lang>`.
- **`TranslatePipe`** (`{{ 'key' | t }}`) — impure on purpose so it re-renders on language change.
- **`LanguageSwitcherComponent`** (ES/EN), currently in the landing header.

**Coverage is incremental.** Done: **landing**, **auth** (login, register, forgot/reset/confirm)
and the **app shell** (top/bottom nav, incl. the ES/EN switcher in the profile menu). Pending
(follow-up PR): dashboard pages (home, motorcycle summary, maintenance, statistics, profile) and the
legal/help long-form text.

When adding user-facing text, add the key to **both** dictionaries; a missing key falls back to
Spanish, then to the key itself (so untranslated strings remain visible, not blank).
