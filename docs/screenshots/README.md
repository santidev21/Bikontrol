# Screenshots

Product screenshots referenced by the root `README.md`. They are **real** captures of the running
app — do not add mockups or placeholders.

## How to capture

1. Run the app locally (`npm run dev`) and sign in (or use the demo if `Demo__Enabled=true`).
2. Use a consistent viewport (e.g. 1440×900 desktop) and the Spanish UI, since that is what users see.
3. Save PNGs here with these exact names:

| File | Screen |
| --- | --- |
| `dashboard.png` | `/dashboard/home` — fleet overview |
| `motorcycle-summary.png` | a motorcycle summary |
| `maintenance-plan.png` | the maintenance plan for a motorcycle |
| `statistics.png` | `/dashboard/statistics` |

4. Uncomment the image block in the root `README.md` "Screenshots" section.

## Rules

- No real personal data in the shots (use the demo account or anonymised test data).
- No browser chrome/OS window frames; crop to the app.
- Keep files reasonably sized (trim, and compress) so the README stays light.
